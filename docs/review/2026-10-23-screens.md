# Review notes, screens, 23 October 2026

**S-37. Recheck requires a later confirmed master-list upload.** The check pane previously
treated every version mismatch as a master-list replacement. Legacy invoices checked
against the file-based sheet therefore showed "The master list has changed" even when
the uploaded master list predated the invoice and no replacement had been saved.
`hasNewerMasterList` in `src/checker/review.ts` now requires a completed live invoice,
known differing versions, and a master-list upload timestamp later than the invoice's
upload timestamp. Missing or invalid dates do not establish a newer master list.
Opening or canceling replacement, including canceling after file preview, does not
create a new version or trigger the prompt. Existing invoice results are preserved.

**S-38. Complete the npm lock file for server installation.** npm 12 rejected clean
installation because root entries for @emnapi/core and @emnapi/runtime 1.11.3 were
missing. Added only those registry-backed entries; existing package versions and

passes after the fix. This validates dependency resolution, not an actual Ubuntu build.
On an existing server checkout, npm install --include=dev repairs the lock file before
building. The local fix has not been committed or pushed.

**S-39. Show the master list immediately and move mapping details into a pop-up.**
Initial uploads now import automatically when one detected table has complete required
mappings. The saved table opens with an informational Column mappings pop-up; the same
button reopens it after refresh. Missing required columns, multiple candidate tables and
manual fallback require confirmation in an editable pop-up with an explicit explanation
of missing fields. A larger source preview stays on the page instead of the mapping form.

Replacements use a separate upload view and always require confirmation in the mapping
pop-up. Canceling before or after preview and rejected saves preserve the current list.
The separate view avoids nested modal focus traps. Backend preview completes missing
fields only when an exact known heading matches one column, fixing an omitted Item name
mapping for Description without choosing between ambiguous headings. Confirmed uploads
store optional columnMapping metadata, including worksheet, header, column names and
selected indices, so the explanation survives refresh/restart. Older saved lists remain
readable and show no mapping button until an import supplies this metadata.
